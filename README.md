# GoalMaster ⚽

GoalMaster is a Football Team Manager desktop application built using Python, PySide6, and SQLite.

## Features

- Login System
- Dashboard Window
- Players Management
- Matches Management
- Statistics Page
- SQLite Database
- Dark Theme UI
- Add / Update / Delete Players
- Save Match Results
- View Team Statistics

## Technologies Used

- Python
- PySide6 (Qt for Python)
- SQLite
- VS Code

## Project Structure

```bash
GoalMaster/
│
├── main.py
├── login.py
├── dashboard.py
├── players.py
├── matches.py
├── stats.py
├── database.py
└── database.db
```

## How To Run

1. Install PySide6

```bash
pip install PySide6
```

2. Run the application

```bash
python main.py
```
